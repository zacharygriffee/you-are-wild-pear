# Agent Handoff: You Are Wild Pear

**Mission:** Linux native host: Electron, Pear/Bare integration, OS storage,
and packaging for the canonical game.

**Agent-safe work:** host, packaging, sandbox, sync, or credential-boundary work
against a declared compatible `you-are-wild` revision.

**Do not own:** gameplay, managed-service policy, public web deployment, or
secrets outside its OS-backed boundary.

**Acceptance:** `npm run check` and `npm run verify:yaw`; name the game revision
and platform assumptions.
